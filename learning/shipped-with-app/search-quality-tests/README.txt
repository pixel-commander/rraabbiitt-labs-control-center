SEARCH QUALITY TESTS

Test questions, expected answers and measured search quality.

lessons/ holds source inputs for this subject.
grades/ holds evaluation measurements against expected answers. It does not hold execution logs.
saved-models/ holds actual saved model files, when a supported process produces them. It does not hold votes or lexical adjustment JSON.

Keep these test questions separate from training inputs. Grades record observed performance of the identified model or search version.
No sample lesson, evaluation, or model files are supplied by this folder setup.
