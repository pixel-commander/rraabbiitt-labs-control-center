LOCAL EDITOR LICENSE NOTES

hooks/useCodeViewer/code-editor.js. That file includes the local editor adapter;
code-editor.d.ts declares its API. No installed CodeMirror package or CDN is used.
The source was tree-shaken and bundled with esbuild. The duplicate adapter input
and one-off downloader were removed; the included JavaScript is now the source
we maintain. The original upstream versions and archive hashes are retained below.
All upstream license and copyright notices follow unchanged.
