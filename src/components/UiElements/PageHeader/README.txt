PageHeader
Use label, Headline, and Right as optional ReactNode values. className is appended to page-header. Props extend HouseKeys.
The component uses two rows (auto auto) and two columns (1fr auto). Right spans both rows. The left track can shrink without overflow. All areas align at the vertical center. The component has no state or handlers. Parent markup supplies headings and skin. Override spacing through tokens, className, or parent CSS. Valid zero, false, and empty string nodes are preserved.
