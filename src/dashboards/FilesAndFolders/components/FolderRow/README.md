# Folder Row

Recursive Files and Folders dashboard row. It takes a precomputed `FolderNode`, controlled expansion/selection state, and optional search visibility. It does not fetch or scan files.

A standard nested list and native buttons provide keyboard access. Expansion and selection are separate actions. Closed and open rows show the same descendant counts and small canvas file-type donut. The selected folder's main chart and direct-file table provide the detailed data.
