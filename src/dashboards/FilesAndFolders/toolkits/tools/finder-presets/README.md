# finder-presets

Save, update and list favorite Files and Folders finder settings in the project database.

Use action list or save. Save needs name, tool, settings with root, and optional favorite. Existing id updates a preset. List may filter root, id and favorite. The preset stores settings; it does not execute them.

Source files are not changed. Discovery refresh and preset saving update only their project database tables. Shared execution owns timings and run history.
